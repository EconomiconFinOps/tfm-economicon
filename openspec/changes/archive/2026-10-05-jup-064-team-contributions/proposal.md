## Why

The team must evidence participation of all four members in each story. Assigned
roles and CI results alone do not prove real contribution. JUP-100 defines the
process but there is no dated cross-story evidence inventory for the memory.

## What Changes

- Add a reproducible dated contribution matrix for all open JUP cards.
- Link GitHub authorship, commits, declared coauthors, reviews, test artifacts,
  documentation and shared CI without inferring individual validation.
- Distinguish current Trello roles, historical PR declarations and missing evidence.
- Document refresh and manual evidence procedures, preserving the existing process.

## Capabilities

### New Capabilities

- team-contributions: traceable contribution inventory and explicit evidence gaps.

### Modified Capabilities

- None.

## Impact

Read-only Python tooling, evidence snapshot, report and maintenance guide.
No product runtime changes or automatic Trello writes. Victor remains leader;
Alejandro prepares the implementation as coauthor. Team review and validation
remain required, and no missing pairing or human contribution is fabricated.
