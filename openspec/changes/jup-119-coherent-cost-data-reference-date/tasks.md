## 1. Sondeo y decisión

- [x] 1.1 Sondeo con un nodo CockroachDB desechable (`docker run`, sin tocar el Compose del proyecto) y la API y la CLI locales, con un CSV de 7 filas que contenía los casos límite de JUP-106 (cero, crédito, dos monedas, importe de 9007199254740993.01, servicio y grupo ausentes, grupos que solo difieren en mayúsculas). Resultado el 2026-10-13: cruzan cero, crédito, dos monedas y ausentes; el importe pasó a `9007199254740994` (pierde los céntimos y la precisión); la API agrupa como máximo por dos campos (con `ServiceName` + `ResourceGroup`, `project` queda vacío; con `Project` + `CostCenter`, servicio y grupo quedan vacíos); la etiqueta `dataset_origin` la rechaza la API; cada ejecución de la CLI tardó unos 133 s, pero ese tiempo era un artefacto: el DSN usaba `localhost`, que en Windows intenta primero IPv6 y espera hasta agotar el tiempo de conexión (200 s con `connect_timeout=200`); con `127.0.0.1`, `initialize()` tarda 2,6 s en una base nueva y 0,4 s ya migrada. Decisiones en `design.md` (D2 y D6). Nodo y proceso de la API retirados.
