## Afirmaciones sobre el modelo por defecto (no son cifras)

Cuando JUP-132 se integre, el modelo por defecto de `economicon-chat` pasa a ser DeepSeek V4.1 Flash y deja de ser GLM-5.2. Los apartados que nombran el modelo por defecto o sus precios, o que distinguen GLM-5.2, DeepSeek V4 Pro y DeepSeek V4.1 Flash, deben revisarse cuando ocurra. Esta lista no sabe cuándo se integra JUP-132.
