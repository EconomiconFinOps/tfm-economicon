# Architecture Decision Records

Los ADR explican decisiones transversales que deben seguir siendo comprensibles despues de cerrar una tarjeta. Usan nombres `ADR-NNNN-descripcion.md` y uno de estos estados: `Proposed`, `Accepted`, `Superseded` o `Deprecated`.

Un ADR permanece `Proposed` mientras el equipo revisa alternativas, costes, seguridad y evidencias. La aprobacion ocurre mediante el pull request asociado; una conversacion por si sola no convierte la propuesta en arquitectura vigente.
