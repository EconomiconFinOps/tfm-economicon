# Atlas ECS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the verified Atlas evaluation package and authenticated Grafana for the disposable AWS rehearsal, without deploying.

**Architecture:** Import the immutable additive SQL in the existing private backend bootstrap. Run Grafana and Prometheus together in one 0.5 vCPU/1 GiB ECS task, using the existing RDS for Grafana metadata and a separate evaluation reader. CloudFront forwards `/grafana` unchanged through the private ALB.

**Tech Stack:** Python/psycopg, PostgreSQL 16, Grafana 11.3.0, Prometheus 2.55.1, Terraform 1.13.3, ECS Fargate, GitHub Actions.

**Spec:** `docs/deployment/aws-defensa.md`, section Entrada Atlas; implementation authorized by the user on 24 October 2026. Original artifact base `ffb5d307772f697cffb8b1e73e6330250e093601`.
